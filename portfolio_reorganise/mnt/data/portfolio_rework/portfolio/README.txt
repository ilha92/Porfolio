PORTFOLIO — ILIAS HAMEL

Structure simplifiée :
- src/App.jsx : toute la logique React du portfolio (données, projets, composants et page).
- src/main.jsx : point d’entrée React.
- src/styles.css : styles et animations.

Pour modifier le portfolio :
1. Les informations personnelles sont au début de App.jsx.
2. Les projets sont dans la section PROJETS.
3. Les compétences sont dans couches et competences.
4. Le parcours est dans parcours.
5. La formation est dans formation.
6. Les styles restent dans styles.css.

Lancer le projet :
node build.mjs
