Ecodeli - Projet annuel 2-ème année

Ce projet vise à concevoir et moderniser le système d’information d’EcoDeli, une entreprise de crowdshipping spécialisée dans la livraison collaborative. Il a pour objectif d’améliorer la gestion interne, la performance des services numériques et la sécurité de l’infrastructure. Le projet inclut la modernisation du site web, la gestion des utilisateurs et l’ajout de nouveaux services. Des technologies web, des bases de données et des solutions systèmes, réseaux et sécurité ont été mises en œuvre. Le résultat est un système d’information plus fiable, sécurisé et évolutif, adapté à la croissance de l’entreprise.

DrivnCook

Ce projet consiste à développer une application web de gestion des franchises pour la société Driv’n Cook. Elle permet de gérer les franchisés, les camions, l’entretien, l’approvisionnement et les ventes. L’application distingue les rôles administrateur et franchisé afin de sécuriser les accès. Le projet a été réalisé en PHP natif, avec une base de données MySQL et un front-end simple en HTML, CSS et JavaScript. Il vise à centraliser les opérations et à améliorer le suivi du réseau de franchises.

PHP HTML Bootstrap Javascript Mysql
