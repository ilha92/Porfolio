Mes Projets

Ecodeli - Projet annuel 2ème année

Contexte

Ce projet vise à concevoir et moderniser le système d’information d’EcoDeli, une entreprise spécialisée dans le crowdshipping et la livraison collaborative. L’objectif est d’améliorer la gestion interne, d’optimiser les performances des services numériques et de renforcer la sécurité de l’infrastructure.

Réalisations
  • 1. Site Internet

    Développement d’un site web moderne et responsive pour faciliter la gestion des opérations.

    Fonctionnalités clés :

    • Gestion des utilisateurs (inscription, authentification, rôles).
    • Suivi des livraisons et des services de crowdshipping.

  • 2. Application Mobile

    Développement d’une application mobile en Kotlin pour permettre aux utilisateurs d’accéder aux services d’EcoDeli en mobilité.

  • 3. Application de Gestion des Données

    Développement d’une application en Java pour centraliser et gérer les données internes de l’entreprise.

Technologies utilisées
  • Frontend : ReactJS, HTML/CSS, JavaScript
  • Backend : NodeJS, Java
  • Base de données : MongoDB
  • Mobile : Kotlin
  • Autres : Solutions systèmes et sécurité

Résultats

Un système d'information complet, composé de :

  • Un site web (ReactJS, NodeJS, MongoDB).
  • Une application mobile (Kotlin).
  • Une application de gestion des données (Java).
  • Une infrastructure fiable, sécurisée et évolutive, adaptée à la croissance d'EcoDeli.

ReactJS Node.js CSS JavaScript Java Kotlin MongoDB

DrivnCook

Contexte

Ce projet consiste en la conception et le développement d’une application web dédiée à la gestion des franchises pour la société Driv’n Cook. L’objectif est de centraliser et optimiser la gestion des franchisés, des camions, de l’entretien, de l’approvisionnement et des ventes.

Fonctionnalités clés :
  • Gestion des franchisés : suivi des informations et des activités.

  • Gestion des camions : maintenance, entretien et disponibilité.

  • Gestion des ventes et de l’approvisionnement : suivi des stocks et des transactions.

  • Sécurité des accès : distinction des rôles administrateur et franchisé pour sécuriser les données.

Technologies utilisées :
  • Backend : Développé en PHP natif.

  • Base de données : MySQL (phpMyAdmin) pour le stockage et la gestion des données.

  • Frontend : Interface simple et intuitive en HTML, CSS, Bootstrap et JavaScript.
Objectif final

Centraliser les opérations et améliorer le suivi et la performance du réseau de franchises.

PHP HTML CSS Bootstrap Javascript Mysql phpMyAdmin

Vitafit - Projet annuel 1er année

Contexte

J’ai participé au développement de Vitafit, une plateforme web dédiée au bien-être et à la santé. Ce projet a été mené en collaboration avec une équipe de trois personnes : deux développeurs backend et un développeur frontend.

Mes contributions

Mon rôle s’est principalement axé sur la gestion de la partie administrateur du site, avec les fonctionnalités suivantes :

  • Gestion des utilisateurs : consultation, modification et suppression des comptes.

  • Gestion des abonnements : suivi des utilisateurs abonnés aux services, attribution de rôles spécifiques pour accéder à des pages réservées aux abonnés.

  • Fonctionnalités d’inscription et de connexion : développement des processus d’authentification et de création de compte.
Objectif

Permettre aux administrateurs de gérer efficacement les utilisateurs et les abonnements, tout en offrant une expérience fluide pour les utilisateurs finaux.
